## 🌟 Key Features

1. **Orthopedic Clinical Care & Treatments**:
   - Robotic Total Knee & Hip Arthroplasty
   - Minimally Invasive Spine Surgery & Endoscopic Discectomy
   - Arthroscopy & Sports Medicine (ACL / PCL / Meniscus)
   - 24x7 Emergency Trauma & Complex Pelvic Fracture Fixation
   - Pediatric Orthopedics & Deformity Correction
   - Advanced Physical Therapy & Rapid Recovery Suite

2. **Frame-by-Frame Scroll Motion & Motion Blur**:
   - Staggered child reveals with `filter: blur(...)` to `blur(0px)` on viewport entry
   - Micro-interactions, smooth interactive carousels and tab transitions
   - Framer Motion animation engine

3. **3-Step OPD Appointment Booking Flow**:
   - Department / Specialty selection
   - Real-time time slot selector (checks against admin slot availability)
   - Patient details and instant Token generation (e.g. `MAD-092`)
   - 1-click WhatsApp confirmation link

4. **Hospital Admin Portal (`/admin`)**:
   - Real-time Metrics: Total bookings, Today's queue, Pending & Confirmed tokens
   - **Master Booking Switch**: Toggle online bookings Open or Closed with a customizable emergency announcement
   - **Time Slot Availability Matrix**: Enable or disable specific OPD time slots (10:00 AM, 11:30 AM, 01:00 PM, 04:30 PM, 06:00 PM, 07:30 PM)
   - **Appointment Management**: Confirm, Mark Completed, Chat on WhatsApp, Call Patient, or Delete
   - **Walk-In Registration**: Register in-person OPD patients directly at the hospital counter
   - **Export to CSV**: Download today's patient queue sheet with 1 click
   - Persistent store synced across all browser tabs

5. **Sub-Pages**:
   - `/` - Home Landing Page
   - `/about` - Hospital Heritage & Clinical Approach
   - `/services` - Orthopedic Treatments & Procedures
   - `/doctors` - Dr. Vinod Kumar's Spotlight & Credentials
   - `/gallery` - Modular Operation Theater & Facility Gallery with Lightbox
   - `/journal` & `/journal/[slug]` - Ortho Journal & Clinical Patient Guides
   - `/contact` - 24x7 Emergency Hotline, OPD Timings, and Contact Form
   - `/admin` - Hospital OPD & Token Management Dashboard

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Niraj91133/Ortho-doc-Madvin-.git

# Navigate to project directory
cd Ortho-doc-Madvin-

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.  
Visit [http://localhost:3000/admin](http://localhost:3000/admin) to access the staff admin dashboard.
